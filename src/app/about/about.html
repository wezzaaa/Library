About Storya

Storya is a single page web application built with Angular that allows users to explore books, discover authors, and manage their personal reading experience.

The application uses the Open Library API to provide access to a large collection of books and authors. Users can search for books, view detailed information, and navigate through different categories.

Storya also offers personalized features such as favorites, a reading list, smart recommendations based on user activity, and search history.
